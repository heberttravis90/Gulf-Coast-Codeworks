What Is RATA Software and What Should It Calculate?

A practical overview of software support for relative accuracy testing and RM-versus-CEMS comparisons.

Gulf Coast Code Works•Updated September 2026•RATA software

A practical overview of software support for relative accuracy testing and RM-versus-CEMS comparisons.

RATA software organizes a comparison workflow

Relative accuracy testing compares reference method results with continuous monitoring system results under the applicable regulatory framework. Software can help organize paired runs, units, bias adjustments, statistics, and run-level review.

The calculations are only part of the job

A dependable tool also needs to handle calibration and bias information, units, run inclusion, confidence terms, method-specific criteria, and the distinction between raw and adjusted results.

The software should show its work

Users should be able to trace the RM value, CEMS value, bias treatment, calculations, and final relative accuracy result instead of receiving only a black-box pass or fail.

Regulatory context still controls

Part 60, Part 75, a permit, test plan, or other applicable requirement can change what must be done. Software should support that review, not replace it.

The useful next step:
If this sounds like the workflow your team is fighting, document where the information starts, where it gets entered again, and what the final deliverable should look like. That is enough to start scoping a better system.
