GULF COAST CODE WORKS — SEO REBUILD

WHAT THIS PACKAGE IS
A complete static multi-page replacement site for gulfcoastcodeworks.com. It keeps the Gulf Coast Code Works branding while giving Google separate pages for the services, locations, portfolio projects, and educational content.

UPLOAD
1. Back up the existing site/repository.
2. Upload EVERYTHING inside this folder to the website repository root, preserving the folders.
3. Deploy as a static site. The root index.html is the homepage.
4. Confirm these URLs load:
   /custom-software/
   /environmental-software/
   /portfolio/reportflow-pro/
   /blog/
   /sitemap.xml

GOOGLE SEARCH CONSOLE
- Add/verify https://gulfcoastcodeworks.com as a Domain property (DNS verification is best).
- Submit: https://gulfcoastcodeworks.com/sitemap.xml
- Request indexing for the homepage, custom-software, environmental-software, reporting-dashboards, and the three portfolio pages first.

GOOGLE ANALYTICS 4
Open /assets/analytics.js and paste the GA4 Measurement ID into the empty id variable. Nothing is sent to Google until an ID is added.

GOOGLE BUSINESS PROFILE
Create/complete the Gulf Coast Code Works profile and use https://gulfcoastcodeworks.com/ as the website. Keep the business name, service area, and description consistent.

CONTACT
The contact form opens the visitor's email app addressed to gulfcoastcodeworks@gmail.com. It does not store visitor data.

PAYMENTS
The payments page remains available but is intentionally noindex. Cash App points to $beardedcajun22.
